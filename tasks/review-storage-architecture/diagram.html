Review Storage Architecture

Option A keeps partition files on the hot write path and hardens the protocol with `pending_appends` plus a fail-closed unhealthy state. Option B moves the active write path into one transactional database and exports sealed logical partitions later.

Option A: Partition Per File

  • Best when physical partition files are a hard requirement.
  • More hot-path failure states to specify and test.

Option B: Single Hot Writer DB

  • Best when hot-path correctness simplicity is the top priority.
  • Moves complexity out of append and into background maintenance.
