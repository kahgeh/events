Projector Checkpoint Failure

The handler loop currently treats failures as log-only and then checkpoints the batch cursor anyway. That turns a transient handler error into a permanent replay gap.

Current Behavior

  • Logs show the failure, but replay safety is already broken.
  • The projection can drift from the event log permanently.

Target Behavior

  • The durable cursor never outruns failed work.
  • Transient handler failures remain recoverable.
