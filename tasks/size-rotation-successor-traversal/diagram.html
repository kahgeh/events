Same-Window Size Rotation Traversal

Same-window partitions created inside one time window share the same start_ms. The current successor query only advances to a strictly larger start_ms, so replay can stop early.

Current Behavior

  • Same-window ordinal partitions are not part of the traversal chain.
  • Replay stalls or skips busy-window data.

Target Behavior

  • Size-based rotation stays replay-safe.
  • Projectors can traverse dense windows completely.
