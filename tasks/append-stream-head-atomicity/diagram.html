Append and Stream Head Atomicity

The current write path commits the event log first and updates the catalog head later. That makes the version index vulnerable to stale reads, wrong error types, and partial failures.

Current Behavior

  • The log and the version index can disagree.
  • Failure handling is ambiguous after commit.
  • OCC is based on stale metadata.

Target Behavior

  • Expected-version semantics stay intact under contention.
  • Catalog drift is prevented or explicitly repairable.
  • The API never lies about commit status.
