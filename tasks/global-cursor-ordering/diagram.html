Global Cursor Ordering Failure

The current cursor advances on (created_at, uuid). That is not a stable global order because multiple events share the same timestamp and UUIDv4 is random.

Current Behavior

  • Same-batch events can replay out of order.
  • Same-millisecond events can fall behind the cursor.
  • Projectors can silently diverge from the write log.

Target Behavior

  • Replay order matches persisted append order.
  • Checkpoint boundaries are safe across restarts.
  • CQRS projectors can rely on deterministic global scans.
